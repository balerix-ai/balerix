# Balerix O5a: the charts — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two Helm charts in `charts/`. `balerix-operator` holds the five definitions, the operator's Deployment and its RBAC. `balerix-daemon` holds one Daemon and the optional flow, web, matrix and github Plugins. Both are checked by `mise run charts` against a real API server, and `e2e-k8s` installs them, so the operator runs inside the kind cluster under the chart's service account (Spec O §24.1–§24.3).

**Architecture:**
- **The definitions** stay generated from `operator/src/api/`. A new `api::chart_crd_files()` writes them as guarded, kept templates into `charts/balerix-operator/templates/crds/`, and `operator/crds/` goes away.
- **A new test binary, `operator/tests/charts_it.rs`,** shells out to `helm template` and runs on the envtest API server the `operator` task already pins:
  - assertions on the rendered objects;
  - a server-side dry-run of every rendering;
  - the controllers running *as the chart's service account* through impersonation. envtest runs `--authorization-mode=RBAC`, so a missing verb fails there.
- **`mise run charts`** runs `helm lint` and that binary. `mise run operator` leaves it out.
- **`e2e-k8s`:** `scripts/operator.sh e2e` `helm install`s the operator chart once into `balerix-system`, cluster-wide, and the journeys `helm install` the daemon chart. The out-of-cluster plumbing (`--resolve`, `--insecure-daemon-url`, `DaemonClient::new_resolving`, `RunConfig::resolve`) is removed.

**Tech Stack:** Rust 1.99, kube 4.2.0 (`client`, `runtime`; `discovery`, impersonation through `Config::auth_info`), k8s-openapi 0.28 (`v1_32`), serde_norway 0.9, Helm 4.3.0 (probed: `helm template` honours a `{{- if }}`-guarded CRD template in `templates/`, and `helm lint` passes it), cargo-nextest, envtest 1.34.1, kind 0.33.0, kubectl 1.34.12, a musl target for the operator image.

**Spec:** `docs/superpowers/specs/2026-10-02-balerix-o-kubernetes-design.md`, §24.1–§24.3. Also read §4, §5.6, §10.2, §14.1, §15, §21.4, §22.3, §22.5 and §23.5, which are context for what this plan changes.

## Global Constraints

- **Branches.** The implementation branch is `feat/charts`, cut from `docs/spec-o-5` (ed2de98, which holds §24). This plan is committed on `docs/spec-o-5` first.
- **Helm is `4.3.0`.** It is pinned in the `charts` and `e2e-k8s` tasks' `tools`, and in `[tools]` nowhere. If a local `mise install` fails with EACCES under `~/.local/share/mise`, run it with `MISE_DATA_DIR`/`MISE_CACHE_DIR` set to a scratch directory.
- **Chart versions.** Both charts are `version: 0.1.0`, `appVersion: "0.2.0"` (the core version on `main`), `apiVersion: v2`, `kubeVersion: ">=1.32.0-0"`.
- **Image defaults.**
  - Operator: `ghcr.io/balerix-ai/balerix-operator`, tag `appVersion` when `image.tag` is empty.
  - Plugin tags, pinned: flow `0.1.1`, web `0.2.1`, matrix `0.1.1`, github `0.1.0`.
- **The operator pod's label.** It carries `app.kubernetes.io/name: balerix-operator`, which is `desired::common::MANAGER`, the label the Daemon's NetworkPolicy admits.
- **The Deployment.** `replicas: 1`, `strategy: Recreate`, no probes, `POD_NAMESPACE` from `metadata.namespace`, `RUST_LOG` from `logLevel` (default `info,kube=warn`).
- **Security context.**
  - Pod: `runAsNonRoot: true`, `runAsUser: 65532`, `seccompProfile: RuntimeDefault`.
  - Container: `allowPrivilegeEscalation: false`, `readOnlyRootFilesystem: true`, `capabilities.drop: [ALL]`.
- **RBAC names.**
  - With `watchNamespaces` empty, a ClusterRole and ClusterRoleBinding named `<release-namespace>-<release>`.
  - Otherwise a Role and RoleBinding named `<release>` in each listed namespace.
  - The ServiceAccount is `<release>` in the release namespace.
- **RBAC rules,** the same in both modes:

  | apiGroups | resources | verbs |
  |---|---|---|
  | `balerix.ai` | `daemons`, `fleets`, `crews`, `agents`, `plugins` | `get`, `list`, `watch`, `create`, `update`, `patch`, `delete` |
  | `balerix.ai` | each kind's `/status` and `/finalizers` | `get`, `update`, `patch` |
  | `""` | `secrets`, `services`, `configmaps`, `persistentvolumeclaims`, `pods` | the seven verbs above |
  | `apps` | `statefulsets`, `deployments` | the seven verbs |
  | `batch` | `jobs` | the seven verbs |
  | `networking.k8s.io` | `networkpolicies` | the seven verbs |
  | `events.k8s.io` | `events` | `create`, `patch` |

- **CRD template text.** Exactly this, with the CRD's YAML between the first and last lines; `metadata.annotations` carries `helm.sh/resource-policy: keep`:

  ```

  # Generated by `mise run crds` from operator/src/api/; do not edit.
  <the CRD's YAML>
  {{- end }}
  ```

- **The daemon chart's `spec.plugins`.** The enabled chart plugins in the fixed order flow, web, matrix, github, then `extraPlugins` in the order given. Plugin objects are named after the plugin.
- **The daemon chart's `needs`** are the plugin manifests' `needs`:
  - flow: `[actions, kv]`
  - web: `[fleets, attach, actions, workspace]`
  - matrix: `[fleets, actions, kv]`
  - github: `[fleets, actions, kv, manage]`
- **No product code** decides anything from chart values beyond what the CLI flags already take.
- **Green after every task:** `mise run check` and `mise run operator`, and `mise run charts` from Task 2 on. CI runs `e2e-k8s`; this host has no docker.

## Review Focus

1. **`watchNamespaces` set, so Roles only.** The operator still reconciles a Daemon, a Plugin and a Fleet down to an Agent pod and publishes Events, and it cannot read Secrets outside the watched namespaces. The kind journey runs only the cluster-wide mode, so this is the only test of it. (Task 2: `the_operator_runs_under_the_charts_namespaced_rbac`.)
2. **A plugin manifest's `needs` changing without the chart.** The Daemon would refuse the plugin's `hello` (its grant would differ from what it asks for). A test compares the chart's defaults with each `plugins/*/package/balerix-plugin.yaml`. (Task 3: `each_plugins_needs_are_its_manifests`.)
3. **`helm upgrade` after a type change, and `helm uninstall`.** The definitions are templates, so an upgrade updates them, and `resource-policy: keep` leaves them, and every Fleet, in place on uninstall. The template text is pinned (Task 1: `a_chart_template_is_guarded_and_kept`), and the API server accepts it (Task 2: `every_rendering_is_accepted_by_the_api_server`).
4. **Two operator releases in one cluster,** say a staging install in a second namespace. Their ClusterRoles must not collide, which is why they are named `<namespace>-<release>`. (Task 2: `the_default_is_one_cluster_role_named_for_the_namespace`.)
5. **Empty optional values.** No storage class, no credential Secret and no `expose` must render *nothing* for those fields, not an empty string the API server or the operator would take as a name. (Task 3: `empty_optionals_render_nothing`.)

```rust
/// §24.1: Helm never upgrades its `crds/` directory, so the definitions
/// are templates: guarded by `crds.install`, kept on `helm uninstall`.
#[test]
fn a_chart_template_is_guarded_and_kept() {
    let plain = api::crd_files().unwrap();
    for ((name, text), (_, yaml)) in api::chart_crd_files().unwrap().iter().zip(&plain) {
        let inner = text
            .strip_prefix(GUARD)
            .and_then(|t| t.strip_suffix(END))
            .unwrap_or_else(|| panic!("{name} is not guarded: {text:.80}"));
        assert!(!inner.contains("{{"), "{name}: template syntax inside a definition");
        let doc: serde_json::Value = serde_norway::from_str(inner).unwrap();
        assert_eq!(
            doc["metadata"]["annotations"]["helm.sh/resource-policy"], "keep",
            "{name}"
        );
        let mut without: serde_json::Value = doc.clone();
        without["metadata"].as_object_mut().unwrap().remove("annotations");
        let plain_doc: serde_json::Value = serde_norway::from_str(yaml).unwrap();
        assert_eq!(without, plain_doc, "{name}: the chart's copy differs beyond the annotation");
    }
}
```

- [ ] **Step 3: Implement `chart_crd_files`** in `operator/src/api/mod.rs`, under `crd_files`:

```rust
/// The definitions as the operator chart's templates (Spec O §24.1):
/// each guarded by `crds.install` and annotated
/// `helm.sh/resource-policy: keep`, so `helm upgrade` updates them and
/// `helm uninstall` leaves them, and every object of their kinds, alone.
pub fn chart_crd_files() -> Result<Vec<(String, String)>, serde_norway::Error> {
    crds()
        .into_iter()
        .map(|mut crd| {
            let name = crd.metadata.name.clone().unwrap_or_default();
            crd.metadata
                .annotations
                .get_or_insert_with(Default::default)
                .insert("helm.sh/resource-policy".into(), "keep".into());
            let yaml = serde_norway::to_string(&crd)?;
            Ok((
                format!("{name}.yaml"),
                format!(
                    "{{{{- if .Values.crds.install }}}}\n\
                     # Generated by `mise run crds` from operator/src/api/; do not edit.\n\
                     {yaml}{{{{- end }}}}\n"
                ),
            ))
        })
        .collect()
}
```

The comment line sits inside the guard, so `a_chart_template_is_guarded_and_kept` parses it along with the YAML, as a YAML comment.

```rust
#![allow(clippy::unwrap_used, clippy::expect_used)]
//! The charts (Spec O §14.1, §24.1–§24.3): `helm template` renderings
//! asserted, applied in a server-side dry run against a real API server,
//! and the controllers run as the operator chart's service account, so a
//! verb its RBAC lacks is a 403 here. Needs `helm` (skips without it,
//! fails under `BALERIX_REQUIRE_TOOLS=1`); the API-server tests need the
//! envtest binaries too. `mise run charts` runs this file.
mod support;

use std::path::{Path, PathBuf};
use std::process::Command;
use std::time::Duration;

use serde_json::{Value, json};

fn helm_ok() -> bool {
    let ok = Command::new("helm")
        .arg("version")
        .output()
        .is_ok_and(|o| o.status.success());
    if !ok {
        assert!(
            std::env::var("BALERIX_REQUIRE_TOOLS").as_deref() != Ok("1"),
            "helm is required (BALERIX_REQUIRE_TOOLS=1); run `mise run charts`"
        );
        eprintln!("skip: no helm");
    }
    ok
}

fn chart(name: &str) -> PathBuf {
    Path::new(env!("CARGO_MANIFEST_DIR")).join("../charts").join(name)
}

/// `helm template <release> <chart> -n <namespace> -f <values>`, one JSON
/// value per non-empty document.
fn render(chart: &Path, release: &str, namespace: &str, values: Value) -> Vec<Value> {
    let file = std::env::temp_dir().join(format!(
        "charts-it-{}-{}.json",
        std::process::id(),
        support::now_nanos()
    ));
    std::fs::write(&file, serde_json::to_vec(&values).unwrap()).unwrap();
    let out = Command::new("helm")
        .args(["template", release])
        .arg(chart)
        .args(["--namespace", namespace, "-f"])
        .arg(&file)
        .output()
        .unwrap();
    let _ = std::fs::remove_file(&file);
    assert!(
        out.status.success(),
        "helm template failed: {}",
        String::from_utf8_lossy(&out.stderr)
    );
    String::from_utf8(out.stdout)
        .unwrap()
        .split("\n---")
        .filter_map(|doc| serde_norway::from_str::<Value>(doc).ok())
        .filter(|v| v.is_object())
        .collect()
}

fn find<'a>(docs: &'a [Value], kind: &str, name: &str) -> &'a Value {
    docs.iter()
        .find(|d| d["kind"] == kind && d["metadata"]["name"] == name)
        .unwrap_or_else(|| panic!("no {kind} {name} in {:?}", kinds(docs)))
}

fn kinds(docs: &[Value]) -> Vec<String> {
    docs.iter()
        .map(|d| format!("{}/{}", d["kind"].as_str().unwrap(), d["metadata"]["name"].as_str().unwrap()))
        .collect()
}

fn operator(namespace: &str, values: Value) -> Vec<Value> {
    render(&chart("balerix-operator"), "balerix-operator", namespace, values)
}

fn container(docs: &[Value]) -> &Value {
    &find(docs, "Deployment", "balerix-operator")["spec"]["template"]["spec"]["containers"][0]
}

fn args(docs: &[Value]) -> Vec<String> {
    serde_json::from_value(container(docs)["args"].clone()).unwrap()
}

        ("apps", "statefulsets"),
```

```rust
/// Server-side apply of each document, as a dry run unless `persist`.
/// Force: the definitions are already there, created by the harness under
/// another field manager.
async fn apply_docs(client: &Client, docs: &[Value], persist: bool) {
    let discovery = Discovery::new(client.clone()).run().await.unwrap();
    for doc in docs {
        let (group, version) = match doc["apiVersion"].as_str().unwrap().split_once('/') {
            Some((g, v)) => (g.to_string(), v.to_string()),
            None => (String::new(), doc["apiVersion"].as_str().unwrap().to_string()),
        };
        let gvk = GroupVersionKind::gvk(&group, &version, doc["kind"].as_str().unwrap());
        let (resource, caps) = discovery
            .resolve_gvk(&gvk)
            .unwrap_or_else(|| panic!("the API server serves no {gvk:?}"));
        let api: Api<DynamicObject> = match (caps.scope, doc["metadata"]["namespace"].as_str()) {
            (kube::discovery::Scope::Namespaced, Some(ns)) => {
                Api::namespaced_with(client.clone(), ns, &resource)
            }
            _ => Api::all_with(client.clone(), &resource),
        };
        let mut params = PatchParams::apply("charts-it").force();
        if !persist {
            params = params.dry_run();
        }
        let name = doc["metadata"]["name"].as_str().unwrap();
        api.patch(name, &params, &Patch::Apply(doc))
            .await
            .unwrap_or_else(|e| panic!("{}/{name}: {e}", doc["kind"]));
    }
}

    apply_docs(client, docs, false).await;
```

```rust
    /// recorded.
    pub fn crew_locked_due(&self, key: &str) -> bool {
        let now = self.now();
        let mut last = self.crew_locked.lock().unwrap_or_else(|e| e.into_inner());
        match last.get(key) {
```

```rust
/// `helm upgrade --install balerix <charts>/balerix-daemon` in `ns` with
/// `values`: what a user does, and what installs and changes the Daemon
/// and its plugins in both journeys.
fn daemon_chart(ns: &str, values: serde_json::Value) {
    let charts = std::env::var("BALERIX_K8S_CHARTS").unwrap();
    let file = std::env::temp_dir().join(format!("e2e-daemon-{ns}.json"));
    std::fs::write(&file, serde_json::to_vec(&values).unwrap()).unwrap();
    let out = Command::new("helm")
        .args(["upgrade", "--install", "balerix"])
        .arg(format!("{charts}/balerix-daemon"))
        .args(["--namespace", ns, "-f"])
        .arg(&file)
        .output()
        .unwrap();
    assert!(
        out.status.success(),
        "helm: {}",
        String::from_utf8_lossy(&out.stderr)
    );
}

/// The Daemon `default`, whose claude is the fake one in the image; the
/// journey's storage, as the Daemon object it replaces had.
fn daemon_values() -> serde_json::Value {
    serde_json::json!({
        "name": "default",
        "storage": { "state": { "size": "1Gi" }, "shared": { "size": "2Gi" }, "agent": { "size": "1Gi" } },
        "defaults": {
            "claude": { "binary": "/usr/local/bin/balerix", "args": ["dev", "fake-claude", "--verbose"], "settings": { "model": "sonnet" } },
            "sandbox": { "network": { "block": false } }
        }
    })
}

/// `name:tag` as the chart's image values.
fn image_values(image: &str) -> serde_json::Value {
    let (repository, tag) = image.rsplit_once(':').expect("an image with a tag");
    serde_json::json!({ "repository": repository, "tag": tag })
}
```
